# GADFLY

A free circuit model of a boost pedal: BASS, TREBLE, LEVEL and a FIXED tone setting. No licence key, no account,
no time limit.

VST3, AU and CLAP for macOS; VST3 and CLAP for Windows; VST3, LV2 and CLAP for Linux.

Downloads are on the [Releases](https://github.com/Paulllux/gadfly-downloads/releases) page.
More about it at [beatforge.nl/gadfly](https://beatforge.nl/gadfly).
